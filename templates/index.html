RAG Pipeline
  1. User query (text / voice)
  2. Voice → text (Web Speech API)
  3. Query cleaning & normalise
  4. Embed query (MiniLM-L6)
  5. FAISS similarity search (top-3)
  6. Inject context into prompt
  7. LLM generates answer
  8. Return answer + sources
